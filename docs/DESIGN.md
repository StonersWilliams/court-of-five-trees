# 庭中有奇树 · 设计文档

本文件记录玩法结构、角色公式、武器/被动、十三位守门人的行为、关卡生成与扩展方式。数值以当前源码为准；调参时优先改配置表，不要把魔法数字散落进逻辑。

---

## 1. 设计目标

| 目标 | 落地方式 |
| --- | --- |
| 「清关—开门—下层—庭主」的紧凑循环 | 5 层 × 7 关（第五层为终局）；关卡 7 固定庭主，关卡 5 为随机事件，行商接在关卡 3，另有关卡 2/4 两条可选侧庭 |
| 每局有构筑差异 | 33 把普通武器 + 8 把角色专属初始武器 + 13 把守门人专属武器、37 种可叠层机制被动、8 位角色、五层十三位守门人 |
| 角色定位明确 | 每个角色独立 `CharacterBase` 子类 + 技能/被动；基础输出交给手持武器 |
| 每层有压迫感，但可读 | 庭主生命/伤害随层增长、60% 二阶段、24 发环；第 2 层起普通关卡有概率变精英 |
| 叙事完整 | 首次进入七幕序章；终局四选一，五种结局 |
| 手机可玩 | 虚拟摇杆 + 技能按钮 + 自动瞄准/自动开火 + 全面板点选 |
| 零依赖、可双击运行 | 经典 IIFE + `window.Ink` + 无构建 |
| 所有美术/音效可复现 | `pixelart.js` 画布绘制；`audio.js` 振荡器/噪声合成 |

## 2. 状态机

`src/game.js` 的 `Game.state`：

```text
intro → title → select → playing ⇄ paused
                            ↓
              event / passive / shop / levelup(兼容)
                            ↓
                    gameover / ending
```

- `intro`：首次进入的七幕序章，每幕约 11 秒；空格/点击继续，Esc/按钮跳过；完成后写 `localStorage['court.introSeen']`。
- `title`：标题、操作说明、静音。
- `select`：八角色卡；读取 `Ink.CharacterList`。
- `playing`：世界更新、关卡战斗、拾取、传送。
- `levelup`：保留状态分支以兼容旧代码，但正常流程不再进入；升级只回复 8 点生命。
- `event`：每层第 5 关随机事件；三选一，选择后开门。
- `passive`：每通过 5 关获得一次，击败庭主额外一次；从全部机制被动中抽 3 条，可重复叠层。`passivePending` 是整数队列。
- `shop`：行商面板；金币或生命购买武器，可离开。
- `paused`：Esc/P/右上角按钮；世界暂停，UI 仍响应。
- `gameover`：玩家生命归零。
- `ending`：第 5 层庭主死亡后踏入「终局」传送阵；四选一，结算五种结局。

### 序章与结局条件

- 序章 7 幕，每幕 11 秒；`Game.advanceIntro()` / `skipIntro()`；完成后写 `localStorage['court.introSeen']`。
- 终局四选一：`white` 白墨、`brush` 朱笔、`fire` 火、`seat` 落座。
- 残稿 `runStats.fragments`：事件「废稿堆 — 捡起残稿」+1，上限 5；五层中随机两层生成废稿堆，其余由庭主掉落补足，保证「第十席」条件可达。
- 真名 `runStats.trueNames` / 庭主印 `runStats.seals`：每击败一位庭主 +1。
- 判定：落座 + 5 残稿 + 9 真名 + 3 印 → **第十席**；火 → **焚稿**；朱笔 → **校勘**；白墨 + 3 残稿 → **清稿**；否则 **退稿**。

### 关卡与房间字段

```js
{
  id, floorIndex, index, type, name,
  mapX, mapY, spine, branch, stage,
  eventId,
  cleared, visited, entered,
  doors: [{ side, targetId, open }],
  connections: [roomId],
  spawnPlan: [{ type, elite, x, y }],
  obstacles: [{ type, x, y, r, variant, destructible, hp, maxHp, broken }],
  bg, torches
}
```

- `stage`：1–7；行商为 0。
- `cleared`：关卡敌人清空 / 事件选择完成；开门。
- `bossUnlocked` = 全部前置 spine 房（含事件房）已清。
- 庭主房进入后自身门保持封闭；只有传送阵能推进，避免离开后丢失传送阵导致软锁。

## 3. 关卡结构

前四层每层 11 个房间（1 准备房 + 7 关 + 1 行商 + 2 条可选侧庭）。进入新层先落在准备房，可三选一：回复 32% 生命 / +8 护盾上限 / +15 金币；准备房不刷怪。

```text
准备房 ─ 关卡 1（战斗） ─ 关卡 2（战斗） ─ 关卡 3（精英） ─ 关卡 4（战斗） ─ 关卡 5（随机事件） ─ 关卡 6（战斗） ─ 关卡 7（庭主）
              │                 │
          侧庭 A（上）       行商／侧庭 B（下）
                                             └──────────────── 行商（支线）
```

- 第二层起，关卡 1/2/4/6 有 16% 概率变成精英房；关卡 3 固定精英。前四层使用直脊/回蛇/双岔/盘阶四套骨架轮换，逐层镜像翻转，节点通道逐层不同。
- 关卡 1/2/4/6：5 + 层数×2 + 0~2 个敌人；关卡 3 额外 +1、关卡 6 额外 +2；上限 24。第 5 层单房可到 22 只以上。
- 中后层部分房间分两波：`waves=2` 的概率随层数从 35% 升到 95%；第一波清空后刷第二波，门保持锁定，第二波清完才算清房。
- 关卡 5：7 种随机事件三选一（含提供基础成长的「旧帖研习室」）；58% 概率先出现守室精英，清掉后才显现事件；选择后才算清房并开门。
- 关卡 2/4 各接一条侧庭（精英或战斗），不阻塞庭主门；小地图未探索房间显示 `?`，未探索通道不画。
- 关卡 7：该层庭主。第一层三选一（松露菌/环日星神/九阳神君），第二层三选一（桃柱/尾刚一郎/六月云之末），第三层三选一（伦敦塔/大大怪/江户十二口女），第四层三选一（巴斯光年/柳铁柱/百越玉女），第五层固定创世者。
- 行商：3 把随机普通武器，金币价随层数上浮；也可支付 25% 最大生命。
- 每通过 5 关触发一次机制被动三选一；击败庭主额外触发一次。清关时中央显示清关横幅。
- 部分中后层房间分两波：第一波清空后刷第二波，门保持锁定；两波清完才计为 cleared。
- 关卡 1–6 全清并处理事件后庭主门解封；进入后门封闭，只能靠传送阵推进。
- 庭主死亡后掉落**该庭主的专属武器**，不会自动装备，并生成传送阵。

### 障碍

- `tree`：五色庭院树，阻挡移动与子弹。
- `pillar`：石柱，阻挡移动与子弹。
- `crate`：木箱，可被玩家子弹打碎，掉 2~5 金币。
- `stone`：低矮石块，阻挡移动与子弹。
- 庭主房固定五棵树；行商房两个木箱；普通房 2 + 层数 + 0~2 个随机障碍。
- 生成时避开房间中心、门点和刷怪点。

## 4. 战斗与伤害管线

### 玩家伤害

```text
damagePlayer(amount, source)
  → 心阅 tryDeflect(source)        完全偏转一次，直接返回
  → 心阅 beforeDamage(amount)      首次伤害 ×0.4
  → 影犬 absorbDamage(amount)      吸收 34%，上限 16 + 层数×2
  → player.takeDamage(amount)
      → 护盾先扣，剩余扣血
      → 荆棘皮反伤（若拥有）
      → 0.6s 无敌帧
      → 死亡 → game.onPlayerDeath()
```

### 敌人伤害

```text
game.damageEnemy(enemy, amount, opts)
  → char.modifyDamageDealt(enemy, amount)
      → 小影：被标记目标 ×1.25
      → 字狱：每层字印 ×1.08
  → enemy.takeDamage(final, opts)
```

- 字印最多 5 层，叠满时减速 0.65× / 1.6s。
- 暴击率 8%，暴击伤害 ×1.65；武器也可暴击。
- 护盾回复：脱战 4.5s 后 1/s。

### 玩家成长

`player.recomputeStats()`：

```text
maxHp      = baseHp × (1 + 0.12 × survival)
maxArmor   = baseArmor + 2 × survival
speed      = baseSpeed × (1 + 0.07 × speed)
damage     = baseDamage × (1 + 0.18 × damage)
atkInterval= baseInterval / (1 + 0.14 × atkSpeed)
skillCdMax = baseCooldown × max(0.55, 1 - 0.10 × cooldown)
```

- 每次升级额外回复 8 点生命。
- 经验曲线：`xpNext = 10 + (level-1)×8 + level^1.25×2`。
- 不再有基础属性三选一；基础成长只由随机事件「旧帖研习室 / 研习旧帖」提供（生命 +12、伤害 +5%、移速 +1.5%）。

## 5. 八位执棋者

### 5.1 棋云 · 弈子 / 棋局·引爆

- 面板：HP 18 / 护盾 4 / 移速 205 / 初始武器 弈者笔 / 冷却 7.5s。
- 输出：由手中武器决定；武器命中视为「普攻命中」。
- **被动「弈子」**：
  - 施放技能后在原地留下 1 枚弈子；
  - 武器每命中 5 次，在命中敌人处额外落 1 枚；
  - 最多 6 枚，持续 26s。
- **主动「棋局·引爆」**：
  - 每枚弈子半径 `96 + enemy.radius`，伤害 `24 + level×2.8 + damageUp×2.2`；
  - 减速 0.5×，持续 2s；
  - 引爆后原地再落 1 枚。
- 定位：中距离铺场，把敌人拉进棋局后一次引爆。

### 5.2 小影 · 残影 / 影袭

- 面板：HP 14 / 护盾 2 / 移速 252 / 初始武器 无光刃 / 冷却 7.0s。
- 输出：由手中武器决定；武器命中视为「普攻命中」。
- **被动「残影」**：
  - 击杀留下可拾取残影，拾取回复 3 点生命；击杀即时回复 1.5；
  - 击杀被标记目标缩短主动冷却 3s。
- **主动「影袭」**：
  - 向瞄准方向突进，距离 `min(178, 距离 + 40)`；
  - 路径附近与落点造成 `18 + level×2.4 + damageUp×1.8`；
  - 标记 5.5s，被标记目标受到小影伤害 ×1.25；
  - 突进期间获得 0.34s 无敌。
- 定位：近战刺客，靠击杀标记目标刷新节奏。

### 5.3 心阅 · 洞察 / 心域

- 面板：HP 20 / 护盾 8 / 移速 195 / 初始武器 听心铃 / 冷却 9.5s。
- 输出：由手中武器决定；武器命中视为「普攻命中」。
- **被动「洞察」**：
  - 进入房间时标记生命上限最高的敌人；
  - 该敌人第一次伤害心阅时减免 60%（只触发一次）。
- **主动「心域」**：
  - 展开 3.4s 心域；
  - 完全偏转下一次受到的伤害；
  - 若结束时未触发，回复 8 点护盾。
- 定位：稳健辅助/防御，适合保护走位失误。

### 5.4 字狱 · 墨痕字印 / 落笔成狱

- 面板：HP 16 / 护盾 3 / 移速 200 / 初始武器 狱毫 / 冷却 11.0s。
- 输出：由手中武器决定；武器命中叠加 1 层字印。
- **被动「墨痕字印」**：
  - 最多 5 层；
  - 每层使字狱对其伤害 +8%；
  - 叠满时减速 0.65× / 1.6s。
- **主动「落笔成狱」**：
  - 在瞄准点生成半径 108 的牢笼，最远 440；
  - 基础伤害 `7 + level×1.15 + damageUp×1.2`；
  - 持续时间 `3.2 + 最高字印层数×0.4`；
  - 每 0.4s 结算一次，伤害 `base × (1 + 0.12×目标字印)`；
  - 普通敌人持续禁锢；精英只在前半段禁锢，之后减速 0.5×；
  - Boss 不被困住，改为减速 0.4× / 0.6s；
  - 结束时「收笔」爆发：`(26 + 8×最高层数) × (1 + 0.1×目标字印)`。
- 定位：中远距离封锁，先铺层数再落狱。

### 5.5 御狶 · 影犬 / 影犬·冲锋

- 面板：HP 17 / 护盾 5 / 移速 210 / 初始武器 唤犬骨哨 / 冷却 8.5s。
- 输出：由手中武器决定；武器命中视为「普攻命中」。
- **被动「影犬」**：
  - 召唤自动索敌/射击的影犬，额外 +4 护盾；
  - 影犬生命 `46 + 层数×7`，自动攻击伤害 `4 + 层数×1.3 + damageUp×1.5`；
  - 影犬距离玩家 300 内时，替玩家吸收 34% 伤害，单次上限 `16 + 层数×2`；
  - 被击破回复 6 护盾，召唤时间缩短 3s；12s 后自动复活。
- **主动「影犬·冲锋」**：
  - 命令影犬冲锋，抵达后嘲讽周围敌人 3.4s；
  - 影犬倒下时先以 50% 生命复活再冲锋。
- 定位：召唤协同，开团、拆火、代承伤害。

### 5.6 小牢鼠 · 余震 / 钻地

- 面板：HP 13 / 护盾 3 / 移速 238 / 初始武器 穿地爪 / 冷却 9.0s。
- **被动「余震」**：破土后的 4 秒内武器伤害 ×1.25。
- **主动「钻地」**：钻地 2s，期间无敌、随走位方向移动；沿途每名敌人受到一次伤害，结束时破土范围伤害并击退。
- 定位：无敌位移穿怪、贴脸爆发。

### 5.7 秋雨 · 湿意 / 秋霖

- 面板：HP 15 / 护盾 6 / 移速 205 / 初始武器 秋霖伞 / 冷却 10.0s。
- **被动「湿意」**：生命低于 40% 时受到伤害 ×0.88。
- **主动「秋霖」**：指定区域生成 5.2s 雨阵，半径 118；每 0.42s 伤害并减速；秋雨在阵内受伤 ×0.55，每 0.55s 回复 3 生命。
- 定位：区域控制与站桩续航。

### 5.8 三瑞 · 分瑞 / 三瑞

- 面板：HP 16 / 护盾 4 / 移速 200 / 初始武器 三瑞印 / 冷却 11.0s。
- **被动「分瑞」**：技能期间玩家受到伤害的 25% 由存活瑞兽分摊。
- **主动「三瑞」**：召唤福/禄/寿三兽，自动分散锁敌、撕咬并沉默（0.32s）；瑞兽有独立生命。结束时存活瑞兽分别回复 18 生命 / +6 护盾 / +20 金币。
- 定位：召唤协同、分担伤害与收尾增益。

## 6. 武器

### 6.1 数据字段

`src/entities/weapon.js` 的 `WeaponDefs`：

```js
{
  id, name, rarity, price, color, visual, icon,
  damage, range, cooldown, damageMult, shots, spread, speed, radius, life,
  pierce, knockback, scale, homing, trail, glow, bounce,
  slow, burn, ink, explode, explodeMult, desc,
  bossOnly, bossId
}
```

- 稀有度：凡品 / 珍品 / 绝品；庭主专属独立于稀有度表。
- `damage` 是武器的基础单发伤害，`range` 决定触屏自动开火距离；角色不再有独立普通攻击。
- 武器命中会触发角色 `onBasicHit`（棋云落子、字狱字印、小影标记等仍生效）。
- 掉落：F1 凡 70% / 珍 30%；F2 凡 22% / 珍 56% / 绝 22%；F3 珍 40% / 绝 60%。
- 庭主死亡只掉落该庭主的 `bossOnly` 专属武器，**不会自动装备**；行商出售 3 把普通武器。
- 按 `G` / 触屏「丢」丢弃当前武器，换枪时旧武器落在脚边；地面武器不会被磁吸，需走近拾取。
- 金币价：基础价 × `1 + 0.12×(层数-1)`；生命价：`ceil(maxHp×0.25)`。

### 6.2 武器清单

| 类别 | 武器 |
| --- | --- |
| 笔与尺 | 春秋笔、判官笔、戒尺、惊堂木、题扇 |
| 伞与简 | 雨巷伞、韦编竹简、活字方阵、广陵琴、琵琶行、梅花箫 |
| 数与器 | 算盘、朱印、松烟砚、徽墨、长卷、编钟、铜镜、司南、六艺骰、孔方镖 |
| 灯与戏 | 走马灯、纸鸢、皮影、傩面 |
| 角色专属 | 弈者笔、无光刃、听心铃、狱毫、唤犬骨哨、穿地爪、秋霖伞、三瑞印 |

特殊词条包括穿透、弹射、撞墙反弹、追踪、减速、点燃、爆炸、墨印。每把武器在 `src/entities/weapon.js` 的 `drawHeld` 中有独立手持轮廓（枪、弩、杖、刀、扇、钟锤等），瞄准时旋转，开火有后坐与枪口火光。

## 7. 机制被动（可叠加）

每通过 5 关三选一，击败庭主额外一次。所有被动都允许重复获取，同名叠层；池子永远从 37 条全量抽取，不会抽空。三选一至少两条来自特性池（复活、额外弹道、环刃、处决、裂弹、缓时、爆裂弹、暴击回血、远距增伤、纸甲、书箧、替页、兽缘等）。全部为机制改变，不提供基础属性成长。HUD 左侧「机缘」栏显示已获被动与层数。

| id | 名称 | 效果 |
| --- | --- | --- |
| ricochet | 折墨 | 子弹命中后折向附近另一名敌人，额外弹射 2 次 |
| wallBounce | 撞墙不回 | 子弹碰墙反弹 1 次 |
| thorn | 荆棘皮 | 受到近身伤害时反弹 35% |
| leech | 汲血 | 每击杀一名敌人回复 2 点生命 |
| magnet | 聚宝 | 经验、金币、武器拾取范围 +80 |

### 8.2 数值

- 生命：`配置生命 × (1.18 + 0.62 × (层数-1))`
- 伤害：`min(15, 配置伤害 × 0.55 × (1.05 + 0.18 × (层数-1)))`
- 移速：`配置移速 × (1 + 0.06 × (层数-1))`
- 经验：`配置经验 + 层数×20`
- 生命 60% 进入二阶段：速度 ×1.22、攻击间隔 ×0.68、24 发环；攻击间隔还受 `floorRush` 随层缩短。
- 创世者在 66% / 33% 两处合书转阶段，每次 1.8 秒无敌并召唤 4 个目录条目；其余守门人在 60% 转阶段。
- 受减速抗性：减速不超过 0.65×，持续时间 ×0.6；不会被字狱完全禁锢。

### 8.3 AI 约定

- `windup(seconds, fn, data)`：先显示预警，再执行。
- `after(seconds, fn)`：延迟弹幕/爆炸。
- `orbit(dt, target, dist)`：保持中距离绕行。
- `fireAt / ring / fieldAt / aoeAt`：基础弹幕工具。
- 每个 AI 方法至少 3 个 pattern，按 `pattern` 轮换；二阶段提高密度。
- 召唤类招式最多同时存在 6 个小怪。
