# 庭中有奇树 · Court of Wondrous Trees

> 奇树成庭，九主守门。

**在线游玩：<https://StonersWilliams.github.io/court-of-five-trees/>**

[![MIT License](https://img.shields.io/badge/license-MIT-e8c170.svg)](LICENSE)
[![No dependencies](https://img.shields.io/badge/runtime%20deps-0-8ef0c8.svg)](package.json)

一个可开源、可游玩的 **HTML5 Canvas 2D 像素地牢肉鸽**。玩家在九层庭院中清怪、拾取 42 把兵刃、选择机制被动、处理随机事件、逛行商，最终在最后一页做出选择。核心循环参考《元气骑士》的「清房 → 开门 → 下层 → Boss」，角色、武器、敌人、Boss、美术与音效全部为原创 / 程序化生成。

- **零运行时依赖、零构建步骤**：原生 JavaScript + Canvas 2D，`index.html` 中按顺序加载脚本。
- **所有美术程序化生成**：16×16 角色/敌人、24×24 庭主、庭院地砖、五树、火把、门、武器图标均由 `src/core/pixelart.js` 在运行时绘制，没有图片素材。
- **所有音效 WebAudio 实时合成**：射击、挥砍、爆炸、受击、升级、Boss 咆哮与环境音乐都由 `src/core/audio.js` 生成。
- **MIT License**：可自由 fork、修改、商用，保留版权声明即可。

## 快速开始

### 方式一：直接双击

打开 `index.html` 即可游玩。Chrome / Edge / Firefox / Safari 的现代版本均可。

> 部分浏览器对 `file://` 下的 WebAudio 或字体加载有额外限制。若音效异常，请使用方式二。

### 方式二：本地服务器（推荐）

需要 Node.js 18+，**不需要 `npm install`**：

```bash
node server.js
# 或
npm start
```

访问 <http://localhost:8080>。可用环境变量：

```bash
PORT=3000 node server.js
HOST=127.0.0.1 node server.js
```

`server.js` 会打印局域网地址，手机与电脑在同一 Wi-Fi 下即可访问。

**小提示**

- 每层有 **7 个关卡**；前六关包含战斗、精英、随机事件，第 7 关是庭主。
- 每层第 2、4、6 关结束后，从三条**机制被动**中选一条；它们改变子弹、击杀、受击或拾取规则，不提供基础属性成长。
- 第 5 关是随机事件，三选一；每层另有 1 个行商支线，可用**金币**或**当前生命**换武器，换下的旧武器会掉在脚边。
- 庭主房进入后门会封闭；击败庭主会掉落该庭主的**专属武器**，并出现通往下一层的传送阵。
- **首次进入会播放七幕序章**（约 77 秒，可随时跳过）；九层通关后进入「最后一页」结局选择。
- 护甲优先吸收伤害，脱战 4.5 秒后以 1.5 点/秒恢复。
- 树、石柱、木箱会阻挡移动与子弹；木箱可以打碎并掉金币。
- 游戏内没有存档；刷新页面会回到标题界面。

### 棋云 · 弈子 / 棋局·引爆

- **被动「弈子」**：释放技能后原地留下弈子；武器每命中 5 次额外落一子，最多 6 枚。
- **主动「棋局·引爆」**：引爆全部弈子，造成范围伤害并减速 50%，持续 2 秒；引爆后原地再落一子。
- 适合边走边铺场，再把整片棋局一次点燃。

### 小影 · 残影 / 影袭

- **被动「残影」**：击杀留下可拾取残影并回血；击杀被标记目标缩短主动冷却 3 秒。
- **主动「影袭」**：向瞄准方向短距突进，对路径与落点造成伤害并标记 5.5 秒；被标记敌人受到小影伤害 +25%。
- 高移速、低容错，靠击杀刷新节奏。

### 心阅 · 洞察 / 心域

- **被动「洞察」**：标记房间内生命上限最高的敌人；其第一次伤害心阅时减免 60%。
- **主动「心域」**：展开 3.4 秒心域，完全偏转下一次伤害；未触发则回复 8 点护甲。
- 输出由武器决定；被动标记仍是心阅的防御节奏核心。

### 字狱 · 墨痕字印 / 落笔成狱

- **被动「墨痕字印」**：武器命中叠加字印，最多 5 层；每层使字狱对其伤害 +8%，叠满短暂减速。
- **主动「落笔成狱」**：在指定位置（最多 440 像素外）书写「狱」字，生成文字牢笼：
  - 普通敌人持续禁锢并每 0.4 秒受伤；
  - 精英只在前半段被禁锢，之后改为减速；
  - Boss 不被完全困住，改为大幅减速；
  - 字印层数延长牢笼时间并提升每跳伤害；
  - 结束时触发「收笔」范围爆发。

### 御狶 · 影犬 / 影犬·冲锋

- **被动「影犬」**：召唤自动攻击的影犬，替玩家承受部分伤害；影犬被击破时回复 6 点护甲并缩短 3 秒召唤时间。**每深入一层多一只，最多 8 只**，其余影犬以 62% 生命跟随。
- **主动「影犬·冲锋」**：命令整群影犬一起冲锋并嘲讽周围敌人 3.4 秒；倒下的影犬会先以 50% 生命复活。
- 影犬会自动索敌、射击、跟随；主动技能是开团与拆火的核心。

### 小牢鼠 · 余震 / 钻地

- **被动「余震」**：破土后的 4 秒内，武器伤害提高 25%。
- **主动「钻地」**：钻入地下 0.95 秒，期间无敌并可位移；沿途敌人受伤，结束时破土而出，造成高额范围伤害与击退。

### 秋雨 · 湿意 / 秋霖

- **被动「湿意」**：生命低于 40% 时，受到的伤害降低 12%。
- **主动「秋霖」**：在指定区域布下 5.2 秒雨阵，持续造成伤害与减速；秋雨站在阵中时减伤 45%，并持续回复生命。

### 三瑞 · 分瑞 / 三瑞

- **被动「分瑞」**：主动技能期间，玩家受到的伤害有 25% 由仍存活的瑞兽分摊。
- **主动「三瑞」**：召唤福、禄、寿三头瑞兽（金、青、粉），自动分散扑咬、沉默敌人；瑞兽各有独立生命。技能结束时，存活瑞兽分别献上生命、护甲与金币。
- 三头瑞兽存在期间会主动撕咬附近敌人，不会与彼此锁同一个目标。

更完整的技能公式、九庭主数值、武器表与扩展指南见 [`docs/DESIGN.md`](docs/DESIGN.md)。

## 地牢循环

- **9 层，每层 7 关 + 1 间准备房**，每层一个主题；进入新层先整备，再推门。
  1. 青苔地宫
  2. 霜钟回廊
  3. 赤花禁苑
  4. 铁律衙门
  5. 无常墨海
  6. 灰烬书库
  7. 镜面水庭
  8. 藤月别院
  9. 白夜经阁
- 每层布局：`关卡 1 战斗`、`关卡 2 战斗`、`关卡 3 精英`、`关卡 4 战斗`、`关卡 5 随机事件`、`关卡 6 战斗`、`关卡 7 庭主`，另有 1 个接在关卡 3 的 `行商` 支线。
- 第二层起，部分普通关卡会随机变成精英房；事件房从 6 种随机事件中抽取，三选一。
- 普通房会在树庭、书库、水廊、四角庭四种骨架中随机，并用树、柱、箱、石改变走位与弹道；准备房只摆灯与箱，不刷怪。
- 关卡 2、4、6 清怪后，从 18 种机制被动中随机三选一；同名被动可重复叠加，池子不会抽空。行商可用金币或生命换武器。
- 庭主房门在关卡 1–6 与事件都处理完后解封；进入后门封闭，击败庭主才出现传送阵。
- 击败第 9 层庭主后，站上「终局」传送阵，进入「最后一页」结局选择。

## 武器

共 **25 把普通武器 + 8 把角色专属初始武器 + 9 把庭主专属武器 = 42 把兵刃**。武器决定基础输出、射程与冷却，角色不再进行独立的普通攻击；角色被动的「普攻命中」由武器命中触发。每把武器都有实体手持模型，随瞄准方向旋转，开火时有后坐/挥砍/枪口火光。

- **笔与尺**：春秋笔（三连墨痕、诛字标记暴击）、判官笔（罪字处决、返还冷却）、戒尺（三连震地）、惊堂木（声波眩晕）、朱印（印文封印）。
- **扇与伞**：题扇（扇骨、格挡反弹）、雨巷伞（旋转、格挡、雨巷减速）、纸鸢（追踪爆炸、断线分裂）、走马灯（灯影灼烧、火焰轮）。
- **书与乐**：韦编竹简（竹片扇形弹幕）、活字方阵（平上去入四类字块）、广陵琴（穿透音波、双环回响）、琵琶行（弹墙音刃、窄道折返）、梅花箫（穿透音针、三连音波）、编钟（震荡眩晕、双钟）。
- **数与器**：算盘（弹跳算珠、清算环绕）、铜镜（反射弹幕、光柱）、司南（标记最强、对被标记目标增伤）、六艺骰（礼乐射御书数六效果）、孔方镖（铜钱弹跳、撒钱阵）。
- **墨与戏**：松烟砚（研墨墨浪、范围减速）、徽墨（旋转墨锭、黑印增伤）、长卷（直线文脉光柱、穿透）、皮影（生旦净丑四式）、傩面（变身 8 秒、爪击、免减速、结束驱散）。
- **角色专属**：弈者笔、无光刃、听心铃、狱毫、唤犬骨哨、穿地爪、秋霖伞、三瑞印。
- **庭主专属**：松露菌杖、环日星盘、九阳神铳、桃柱花杖、尾刚名刀、六月云伞、伦敦钟锤、大大怪骨棒、江户十二口扇。

武器可带穿透、弹射、追踪、减速、点燃、爆炸等词条，并各自拥有 `special` 节奏。庭主死亡后会在原地掉落**该庭主的专属武器**，不会自动装备；按 `G` / 触屏「丢」可以丢弃当前武器，走到地面武器上即可拾取，换枪时旧武器会自动落在脚边。行商出售 3 把普通武器，金币价随层数上浮，也可以支付 25% 最大生命购买，换下的旧武器同样会落地。

## 序章与结局

- **七幕序章**：首次进入自动播放，每幕约 11 秒，总计约 77 秒；`空格/点击继续` 可加速，`Esc/跳过序章` 直接进入标题。看过后写入 `localStorage`，不再强制播放。
- **最后一页**：击败第 9 层庭主、站上「终局」传送阵后进入四选一——**白墨 / 朱笔 / 火 / 落座**。
- 条件：`残稿`（九层中固定有五层出现「废稿堆」，可收集，最多 5）、`庭主真名`（每击败一位庭主 +1）、`庭主印`（每击败一位庭主 +1）。
- 五种结局：**退稿**（条件不足）、**清稿**（白墨 + 残稿≥3）、**校勘**（朱笔）、**焚稿**（火）、**第十席**（落座 + 残稿 5 + 真名 9 + 庭主印≥3）。

## 局内成长

击杀掉落经验；升级只回复 8 点生命并刷新等级，**不提供基础属性三选一**。基础生命/护甲/移速来自角色，基础输出/射速/射程来自武器；局内成长只有每层第 2、4、6 关后的机制被动三选一。经验曲线：`10 + (等级-1)×8 + 等级^1.25×2`。

### 架构约定

- 所有模块都是经典 IIFE，挂到 `window.Ink` 上；**没有 ES Module、没有打包器**，所以 `file://` 双击也能运行。
- `window.Ink` 是唯一全局命名空间；共享常量：
  - `Ink.ARENA = {x:48, y:94, w:864, h:480}`：可战斗区域。
  - `Ink.DOOR_POINTS`：四向门坐标。
  - `Ink.FLOOR_COUNT = 9`：九层庭院。
- `Game` 拥有世界数组：`player / dog / enemies / projectiles / effects / pickups / obstacles`。
- 角色通过 `Ink.registerCharacter(def)` 注册；技能钩子定义在 `Ink.CharacterBase`。
- 武器通过 `Ink.Weapons` 取用；被动通过 `Ink.Passives` / `Ink.PassiveList` 取用。
- 敌人通过 `Ink.spawnEnemy(game,type,x,y,opts)` 生成；庭主通过 `Ink.spawnBoss(game,id,x,y)`。
- 所有视觉资源都可由 `Ink.Art.sprite(key, frame, tint)` 取得；可直接替换 `pixelart.js` 而不影响玩法。
- 房间数据由 `src/dungeon/dungeon.js` 生成，包含 `stage / type / obstacles / spawnPlan / doors`。

## 扩展指南

### 添加一个新角色

1. 新建 `src/characters/myhero.js`。
2. 继承 `Ink.CharacterBase`，实现 `basicAttack()`、`useSkill()`，按需实现 `onKill / onBasicHit / beforeDamage / tryDeflect / drawWorld`。
3. 用 `Ink.registerCharacter({...})` 注册，填入 `hp/armor/speed/damage/atkInterval/range/cooldown` 等字段。
4. 在 `index.html` 中把脚本加到 `characters.js` 之后。

角色选择界面会自动读取 `Ink.CharacterList`，无需改 UI。

### 添加一把武器

在 `src/entities/weapon.js` 的 `DEFS` 中增加一条配置，填 `rarity / price / cooldown / damage / range / shape / shots / spread / special` 等字段，再加入对应稀有度的掉落池。手持模型在 `drawHeld` 的 `shape` 分支中实现，`drawIcon` 会复用它；专属效果在 `player.weaponSpecial` 中分发。

### 添加一位庭主

1. 在 `src/entities/boss.js` 的 `BOSSES` 中增加配置。
2. 实现同名 AI 方法，使用 `windup / after / fireAt / ring / fieldAt / aoeAt` 组合招式。
3. 在 `src/dungeon/dungeon.js` 的 `BOSS_POOLS` 中加入对应层级。
4. 在 `src/core/pixelart.js` 的 `BOSS_BUILDERS` 中画一个 24×24 立绘。

### 调整数值

- 角色面板：各角色文件底部的 `Ink.registerCharacter`。
- 武器伤害/冷却：`src/entities/weapon.js` 的 `BASE_DAMAGE` 与各武器 `cooldown`。
- 角色基础面板：`src/entities/player.js` 的 `recomputeStats`（不再有局内属性成长）。
- 武器/被动：`src/entities/weapon.js` / `src/core/passives.js`。
- 敌人/庭主：`src/entities/enemy.js` / `boss.js` 顶部配置表。
- 关卡与障碍：`src/dungeon/dungeon.js` 的 `_makeRoom` / `_buildObstacles`。

## 兼容性与已知限制

- 目标是现代桌面与移动浏览器；建议横屏游玩。
- 移动端为「虚拟摇杆 + 技能按钮 + 自动瞄准/自动开火」，被动、商店、武器丢弃按钮均可直接点选。
- 游戏内没有存档；刷新页面会回到标题界面。
- 所有音效为实时合成，首次点击/按键后才会解锁音频上下文。
- 没有使用任何第三方库、字体文件或图片素材。界面字体回退到系统中文字体。
